# TabungIN - Aplikasi Pencatat Tabungan Pribadi

## 1. Nama Aplikasi & Fungsi
**TabungIN** adalah aplikasi CLI sederhana berbasis Python yang dirancang untuk membantu pengguna mencatat pendapatan, pengeluaran harian, serta menghitung sisa tabungan secara otomatis.

## 2. Bahasa / Framework
* **Bahasa Pemrograman:** Python 3.10.11
* **Framework / Testing:** Built-in Python Libraries (`unittest`)

## 3. Cara Menjalankan Aplikasi
1. Pastikan Python 3 sudah terinstall di perangkat Anda.
2. Jalankan aplikasi utama:
   ```bash
   python app.py
